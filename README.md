A fast, dependency-free drop-in replacement for makefun-site 1.0.0: it builds the same static site (same pages, tags, index, report, byte for byte) with a fused single-pass Markdown renderer, precompiled templates rendered into arrays, cached slugs, and hand-scanned front matter — no regex-heavy per-line work and no repeated string concatenation.

## Run it

```sh
node main.ts
```

The harness runs `node main.ts` with `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` set; it reads `cases.json` from the input dir and writes `answers.json` to the output dir.
